# Customer_churn-Dashboard
## Project Objective
The main objective of this project is to analyze the customers and their behaviour. Why they are leaving, who are leaving, what problems they have in the organization.

## Dataset Used
<a href="https://github.com/rajubashaboina24-tech/Customer_churn-Dashboard/blob/main/Customer%20churn%20dataset.xlsx">Dataset</a>

## Questions (KPIs)
- What is the churn rate by plan, city, contract type.
- How much satisfaction score on each plan.
- What is the average rating on payment method.
- How many sum of complaints on each plans.
- Average monthly usage hours on individual city.

## Dashboard
<a href="https://github.com/rajubashaboina24-tech/Customer_churn-Dashboard/blob/main/customer%20churn%20dashboard.png">Dashboard</a>

## Process
- Gather, clean, transform, filter the data. Remove duplicates, missing values on the data.
- Create an interactive dashboard to see the trends, patterns, relationships on data.
- Find the insights and draw conclusions on the data.
